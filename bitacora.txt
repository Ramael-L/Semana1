# BITÁCORA — PROYECTO RUEDA LIBRE

**Versión 0.1 — Registro del proceso de desarrollo**

 Rueda Libre  
 Sitio web para el alquiler de bicicletas, recorridos guiados y servicios relacionados en Medellín.

---

 — Preparación del proyecto y funcionamiento de la web

 Estructura inicial

Se establece el proyecto Rueda Libre como un sitio web organizado mediante HTML, CSS y JavaScript.

La estructura inicial contempla:

- `index.html`: documento principal.
- `paginas/`: páginas secundarias.
- `img/`: imágenes y recursos gráficos.
- `bitacora.txt`: registro del proceso de desarrollo.
- `css/styles.css`: hoja de estilos del proyecto.

Se utiliza Visual Studio Code como editor, Live Server para visualizar el sitio y Git para controlar las versiones del código.

 ¿Qué sucede cuando ingresamos a una página web?

Cuando una persona escribe una dirección en el navegador, este realiza una petición HTTP al servidor para solicitar un recurso, por ejemplo, un documento HTML.

La petición y la respuesta contienen información que podemos observar desde las herramientas de desarrollo del navegador, específicamente en la pestaña Network.


Registro de la petición local:

- URL completa: 
- Protocolo: 
- Host: 
- Puerto: 
- Ruta: 
- Método: GET.
- Estado esperado: 200 OK, cuando el documento se carga correctamente.

**Prueba de una ruta inexistente:**

Se debe solicitar una dirección que no corresponda a ningún archivo existente, por ejemplo, `/promociones.html`.

El código 404 Not Found indica que el servidor no encontró el recurso solicitado.

Nota: los códigos 200 y 404 corresponden a los resultados esperados de las pruebas; se deben confirmar en Network y registrar los valores observados.

### 3. Funciones de HTML, CSS y JavaScript

**HTML — Estructura**

HTML permite organizar el contenido de una página web mediante etiquetas.

Ejemplo: crear un título, un párrafo o una sección de servicios.

**CSS — Presentación**

CSS permite definir la apariencia visual de la página: colores, tamaños, espacios, tipografías y distribución de los elementos.

Ejemplo: establecer el color verde de la marca Rueda Libre y organizar las tarjetas de servicios.

**JavaScript — Interactividad**

JavaScript permite agregar comportamientos e interacciones.

Ejemplo: crear un botón que permita cambiar entre el modo claro y el modo oscuro.

 — Estructura semántica y contenido de inicio

 Organización de la página principal

Se trabaja en la construcción de `index.html`, utilizando una jerarquía correcta de encabezados y elementos semánticos.

La página debe contener un único título principal (`h1`) y las siguientes secciones:

- ¿Quiénes somos?
- Nuestros servicios.
- ¿Cómo alquilar?
- Encuéntranos.

Cada servicio debe tener un subtítulo y un párrafo descriptivo.

 Elementos HTML utilizados

- `h1`, `h2` y `h3`: organizan los títulos y subtítulos.
- `p`: permite escribir párrafos.
- `strong`: resalta información importante.
- `em`: proporciona énfasis a una expresión.
- `ul`: crea listas con viñetas.
- `ol`: crea listas numeradas.
- `li`: representa cada elemento de una lista.
- `img`: permite insertar imágenes.
- `a`: crea enlaces.

 Imágenes y accesibilidad

Se utilizan imágenes almacenadas en la carpeta `img/`.

Cada imagen debe contar con:

- `src`: ubicación del archivo.
- `alt`: descripción alternativa de la imagen.
- `width`: ancho definido.

Las rutas deben ser relativas y no deben depender de ubicaciones locales del computador.

 Tipos de enlaces

Se trabajan tres tipos de enlaces:

- Enlace absoluto: permite visitar una dirección externa, como una ubicación en un mapa.
- Enlace de correo: utiliza `mailto:` para abrir la aplicación de correo.
- Enlace interno: utiliza un identificador `id` y un fragmento como `#encuentranos` para desplazarse a una sección de la misma página.

También se revisa el uso de `target="_blank"` para abrir un enlace en otra pestaña.

 Validación del documento

Mediante DevTools, en el panel Elements, se revisa el árbol del documento para comprobar que las etiquetas estén correctamente anidadas y cerradas.

Se debe verificar que exista un único `h1`, que las secciones tengan una jerarquía coherente y que no existan elementos ubicados dentro de contenedores incorrectos.

 Creación de tarifas.html

Se trabaja en la página `paginas/tarifas.html`, cuyo propósito es presentar los precios de alquiler y los recorridos guiados.

 Tabla de tarifas de bicicletas

| Tipo de bicicleta | 1 hora | Medio día (4 h) | Día completo |
|---|---:|---:|---:|
| Urbana | $10.000 | $30.000 | $50.000 |
| Montaña | $15.000 | $45.000 | $70.000 |
| Eléctrica | $25.000 | $70.000 | $110.000 |

 Tabla de recorridos guiados

| Recorrido | Distancia | Duración | Nivel | Precio |
|---|---:|---:|---|---:|
| Río y Parques | 12 km | 2 h | Fácil | $45.000 |
| Sabores de Barrio | 18 km | 3 h | Medio | $60.000 |

Todas las tarifas incluyen casco y candado. Los recorridos se realizan sábados y domingos a las 7:00 a. m.

Qué llevar: ropa cómoda, agua, protector solar y documento de identidad.

 Estructura de las tablas

Se utilizan las siguientes etiquetas:

- `table`: crea la tabla.
- `caption`: proporciona el título de la tabla.
- `thead`: agrupa los encabezados.
- `tbody`: agrupa los datos.
- `tr`: representa una fila.
- `th`: representa una celda de encabezado.
- `td`: representa una celda de datos.
- `scope`: identifica si un encabezado corresponde a una fila o columna.

Las tablas se utilizan para presentar datos relacionados, no para organizar visualmente toda la página.

 Rutas relativas

Se estudia cómo conectar documentos que se encuentran en carpetas diferentes.

Ejemplos:

- Desde `index.html` hacia tarifas: `paginas/tarifas.html`.
- Desde `index.html` hacia reservas: `paginas/reservas.html`.
- Desde `paginas/tarifas.html` hacia inicio: `../index.html`.
- Desde `paginas/reservas.html` hacia inicio: `../index.html`.

El símbolo `../` permite salir de la carpeta actual y regresar al nivel superior.

También se utiliza la combinación de archivo y fragmento para acceder directamente a una sección de otra página, por ejemplo:

`paginas/tarifas.html#recorridos`

 Formularios y validación de datos

Formulario de reservas

Se trabaja en la creación de un formulario para recopilar los datos necesarios para reservar una bicicleta.

El formulario se organiza en tres grupos:

- Tus datos.
- Tu alquiler.
- Confirmación.

Se estudia el uso de `form`, `fieldset`, `legend`, `label`, `input`, `select`, `textarea` y `button`.

 Atributos de los formularios

- `action`: indica el destino al que se envían los datos.
- `method`: define el método de envío.
- `name`: identifica el dato enviado.
- `type`: determina el tipo de control.
- `required`: establece que un campo es obligatorio.
- `minlength` y `maxlength`: establecen límites de longitud.
- `min` y `max`: establecen límites numéricos o de fecha.
- `pattern`: permite establecer un patrón de validación.
- `autocomplete`: facilita el ingreso de información.

Se estudia el método POST para el envío de datos, teniendo presente que un formulario HTML sin un servidor que procese la información no almacena automáticamente las reservas.

 Validaciones específicas

Se consideran las siguientes reglas:

- Nombre: mínimo tres caracteres.
- Documento: entre seis y diez dígitos.
- Celular: diez dígitos, comenzando por 3.
- Fecha: dentro del período permitido.
- Cantidad: mínimo una bicicleta y máximo seis.
- Correo: formato válido.
- Términos: aceptación obligatoria.

 Pruebas de validación

La siguiente tabla registra los casos que deben probarse en el navegador:

| N.º | Prueba | Resultado esperado |

| 1 | Enviar el formulario vacío | El navegador impide el envío. |
| 2 | Ingresar un nombre demasiado corto | Se rechaza por longitud mínima. |
| 3 | Ingresar un correo inválido | Se solicita un correo válido. |
| 4 | Ingresar un documento con letras | Se rechaza el formato. |
| 5 | Ingresar un celular con formato incorrecto | Se rechaza el patrón. |
| 6 | Seleccionar una fecha fuera del rango | Se rechaza la fecha. |
| 7 | Ingresar una cantidad inferior a 1 o superior a 6 | Se rechaza la cantidad. |
| 8 | No aceptar los términos | Se impide el envío. |

Estas pruebas deben ejecutarse y registrarse con sus resultados reales.

Accesibilidad del formulario

Se debe comprobar que todos los controles tengan etiquetas asociadas, que los grupos estén identificados y que sea posible recorrer el formulario utilizando únicamente el teclado.

Se revisa el orden de navegación con Tab, Shift + Tab y las teclas correspondientes a cada control.



Fundamentos de CSS y personalización visual

 ¿Qué es CSS?

CSS es el lenguaje utilizado para definir la presentación visual de los documentos HTML.

Permite controlar colores, tipografías, tamaños, espacios, bordes y distribución.

 Variables CSS

Se utilizan variables dentro de `:root` para centralizar los colores y otros valores del proyecto.

Ejemplo:

```css
:root {
    --verde-ruta: #1E7A4F;
    --naranja-pedal: #9a5a0d;
    --azul-noche: #002574;
    --background-color: #FAF6EF;
    --text-color: #5B6470;
}
```

Para utilizar una variable se emplea `var()`.

Ejemplo:

```css
body {
    background-color: var(--background-color);
    color: var(--text-color);
}
```

Esto permite mantener una identidad visual coherente y modificar los colores desde un solo lugar.


Se estudia el modelo de caja de CSS:

- Content: contenido del elemento.
- Padding: espacio interno.
- Border: borde del elemento.
- Margin: espacio externo.

También se utiliza `box-sizing: border-box` para facilitar el cálculo de las dimensiones.

 Tipografías y estilos

Se trabajan las fuentes Montserrat y Open Sans.

Se utilizan propiedades como:

- `font-family`.
- `font-size`.
- `font-weight`.
- `line-height`.
- `color`.
- `background-color`.
- `border-radius`.
- `padding`.
- `margin`.

Se organiza la hoja de estilos para evitar reglas duplicadas y mantener una estructura clara.



 Flexbox

Flexbox permite distribuir y alinear elementos dentro de un contenedor.

Propiedades estudiadas:

- `display: flex`: activa el modelo flexible.
- `flex-direction`: define la dirección de los elementos.
- `flex-wrap`: permite que los elementos pasen a otra línea.
- `justify-content`: distribuye los elementos en el eje principal.
- `align-items`: alinea los elementos en el eje transversal.
- `gap`: establece espacios entre elementos.

Se aplica principalmente a la navegación y a la distribución de elementos del encabezado.

 CSS Grid

Grid permite organizar elementos en filas y columnas.

Propiedades estudiadas:

- `display: grid`.
- `grid-template-columns`.
- `grid-template-rows`.
- `grid-column`.
- `gap`.
- `repeat()`.
- `minmax()`.
- `fr`.

Ejemplo:

```css
#servicios {
    display: grid;
    grid-template-columns: repeat(3, minmax(0, 1fr));
    gap: 1rem;
}
```

Esta distribución permite organizar las tarjetas de servicios en columnas.

 Diseño responsive

El diseño responsive permite adaptar la página a diferentes tamaños de pantalla.

Se estudian las media queries mediante `@media`.

Ejemplo:

```css
@media (max-width: 600px) {
    #servicios {
        grid-template-columns: 1fr;
    }
}
```

También se trabaja con imágenes flexibles, anchos máximos y contenedores que permiten desplazamiento horizontal cuando las tablas son demasiado anchas.




 ¿Qué es Bootstrap?

Bootstrap es un framework CSS que proporciona componentes y clases prediseñadas para desarrollar interfaces web.

Se trabaja mediante su CDN para realizar una práctica independiente.

 Clases estudiadas

- `container`: establece un contenedor.
- `row`: crea una fila.
- `col-12`: ocupa doce columnas.
- `col-md-6`: ocupa seis columnas desde el punto de ruptura mediano.
- `col-lg-4`: ocupa cuatro columnas desde el punto de ruptura grande.
- `g-3`: establece separación entre columnas y filas.
- `card`: crea una tarjeta.
- `card-body`: organiza el contenido de una tarjeta.
- `btn`: aplica estilos de botón.
- `btn-success`: aplica el estilo verde de Bootstrap.
- `navbar`: permite crear una barra de navegación.

 Diseño adaptable en Bootstrap

Se estudia cómo las clases de columnas cambian según el tamaño de pantalla.

Por ejemplo:

`col-12 col-md-6 col-lg-4`

Esto permite que un elemento ocupe todo el ancho en pantallas pequeñas, la mitad en pantallas medianas y un tercio en pantallas grandes.



 Personalización
Se estudia cómo combinar los estilos de Bootstrap con CSS propio para adaptar los componentes a la identidad visual de Rueda Libre.


 ¿Qué es Tailwind CSS?

Tailwind CSS es un framework que utiliza clases utilitarias para construir diseños directamente desde el HTML.

En lugar de depender exclusivamente de componentes prediseñados, permite combinar clases que controlan propiedades específicas.

 Clases utilitarias estudiadas

- `bg-stone-100`: establece un fondo claro.
- `text-green-800`: establece un color de texto.
- `text-3xl`: establece un tamaño de texto.
- `font-bold`: aplica negrita.
- `p-5`: establece espacio interno.
- `mb-4`: establece margen inferior.
- `rounded-lg`: redondea los bordes.
- `shadow`: agrega una sombra.
- `grid`: activa CSS Grid.
- `grid-cols-1`: establece una columna.
- `md:grid-cols-2`: establece dos columnas desde el punto de ruptura mediano.
- `lg:grid-cols-3`: establece tres columnas desde el punto de ruptura grande.
- `hover:bg-green-900`: cambia el fondo cuando el usuario pasa el cursor.

 Diseño adaptable

Tailwind utiliza prefijos como `sm:`, `md:` y `lg:` para aplicar estilos según el tamaño de pantalla.

Esto permite construir interfaces adaptables combinando clases utilitarias.

 Modo oscuro

Se estudia el prefijo `dark:` para aplicar estilos cuando la página se encuentra en modo oscuro.

Ejemplo:

```html
<body class="bg-stone-100 text-slate-800 dark:bg-slate-950 dark:text-white">
```

También se puede utilizar JavaScript para activar o desactivar la clase `dark` mediante un botón.



  Tailwind CLI y comparación de frameworks



 Tailwind mediante CLI
Se estudia la instalación de Tailwind CSS utilizando Node.js y npm.

Conceptos:

- Node.js: entorno que permite ejecutar JavaScript fuera del navegador.
- npm: administrador de paquetes.
- CLI: interfaz de línea de comandos.
- `package.json`: archivo que registra información y dependencias del proyecto.
- `node_modules`: carpeta donde se instalan los paquetes.
- `@import "tailwindcss"`: importa los estilos de Tailwind.
- `--watch`: mantiene el proceso atento a los cambios.

Se trabaja con un archivo CSS de entrada y un archivo CSS de salida generado mediante la herramienta CLI.

Comando de referencia:

powershell
npx @tailwindcss/cli -i ./src/input.css -o ./css/tailwind-output.css --watch

 Comparación entre Bootstrap y Tailwind

| Característica | Bootstrap | Tailwind CSS |
|---|---|---|
| Enfoque | Componentes y clases prediseñadas | Clases utilitarias |
| Personalización | Se modifican los estilos existentes | Se combinan utilidades |
| Desarrollo | Permite construir rápidamente con componentes | Permite controlar cada propiedad del diseño |
| Responsive | Grid y breakpoints | Prefijos responsive |
| Uso | Interfaces con componentes preparados | Interfaces personalizadas |

Ambos frameworks permiten desarrollar sitios adaptables. La elección depende de las necesidades del proyecto y del nivel de personalización requerido.
