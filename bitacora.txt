BITÁCORA - RUEDA LIBRE
Noviembre de 2026

Mi proyecto es una página de alquiler de bicicletas en Medellín. La hice para practicar lo que estamos aprendiendo en Riwi y entender cómo se conectan varias páginas web.

VERSIÓN 0.1 - PRIMEROS PASOS
Empecé organizando las carpetas, las imágenes y las páginas. Aprendí a usar enlaces relativos para pasar de Inicio a Tarifas y Reservas. También practiqué la estructura básica de HTML y el uso de Live Server. Con Git fui guardando los avances.

VERSIÓN 0.2 - CONTENIDO Y FORMULARIOS
Añadí los servicios, la flota, las rutas y las tablas de precios. Para organizarlas usé section, article y encabezados. En las tablas incluí caption y th para que se entiendan mejor.

En Reservas trabajé con label, input, select y fieldset. Usé required, min, max y pattern para comprobar datos desde HTML. El formulario es una demostración académica: no guarda ni envía reservas reales.

VERSIÓN 0.3 - DISEÑO Y ADAPTACIÓN
Organicé los estilos en un archivo CSS compartido. Usé variables para repetir colores y espacios sin escribirlos muchas veces. Flexbox me ayudó con los menús y botones, y Grid con las tarjetas, la portada y el formulario. También añadí cambios para que la página se adapte a distintos tamaños de pantalla.

RUEDA NOCTURNA Y PORTAFOLIO
Creé Rueda Nocturna con Tailwind enlazado por CDN, como indicó el profesor. Conservé su diseño oscuro y preparé tres archivos: prototipo, componentes e index. El index incluye las rutas y un formulario de inscripción de prueba.

En el portafolio mostré mis proyectos. Para conocer lo básico de Bootstrap añadí solo una insignia en el portafolio y un aviso en Rueda Nocturna. No usamos los ejercicios completos de Bootstrap porque el profesor indicó omitirlos.

LO QUE ME QUEDA POR COMPROBAR
- Abrir todas las páginas con Live Server y revisar enlaces e imágenes.
- Usar DevTools Network para anotar URL, host, puerto, una respuesta 200 y una prueba 404.
- Probar el formulario con datos correctos y errores (campos vacíos, correo, documento, teléfono, fecha, cantidad y aceptación).
- Revisar el teclado y el foco visible.
- Comprobar cómo se ve en 360, 768, 1024 y 1280 píxeles.
- Pasar los HTML por el validador W3C.
- Publicar en GitHub Pages y guardar el enlace y las capturas.

Al revisar los archivos no aparecieron rutas internas rotas ni identificadores duplicados, pero eso no reemplaza las pruebas en el navegador. Prefiero dejar estas comprobaciones como pendientes hasta hacerlas de verdad.

CONCLUSIÓN
Con Rueda Libre practiqué cómo se complementan HTML, CSS y Tailwind. Mi idea es mantener el código sencillo para poder explicar qué hace cada parte y seguir mejorándolo mientras aprendo.
