Función de HTML, CSS y JavaScript

- HTML: define la estructura y el contenido del sitio. Por ejemplo, permite crear títulos, secciones, tablas de tarifas, imágenes y formularios de reserva.
- CSS: controla la apariencia visual. Por ejemplo, permite cambiar los colores, los tamaños de letra, los espacios y la distribución de las secciones.
- JavaScript: permite agregar interactividad y comportamiento. Por ejemplo, puede validar los datos de un formulario o mostrar mensajes al usuario.
 
 
 Organización semántica de la página principal

Organicé `index.html` con un único título principal y las secciones ¿Quiénes somos?, Nuestros servicios, ¿Cómo alquilar? y Encuéntranos.
Cada servicio tiene su propio subtítulo y párrafo. Utilicé `strong` para destacar información importante, como que el alquiler incluye casco y candado, y `em` para dar énfasis a determinados textos.
Presenté los cuatro pasos para alquilar mediante una lista ordenada (`ol`) y los tres beneficios del servicio mediante una lista desordenada (`ul`).
Agregué imágenes de portada, bicicletas y recorridos desde la carpeta `img/`, con rutas relativas, textos alternativos descriptivos mediante `alt` y un ancho definido.
También incorporé un enlace externo a una ubicación en un mapa, un enlace de correo mediante `mailto:` y un enlace interno a la sección Encuéntranos.
Finalmente, revisé la estructura en la pestaña Elements de DevTools para comprobar la organización y el cierre correcto de las etiquetas HTML.



 Página de tarifas y recorridos guiados

Creé `paginas/tarifas.html` con su propia estructura HTML, título de pestaña y descripción para buscadores.
Construí una tabla de tarifas de alquiler y otra de recorridos guiados. Utilicé `caption` para identificar las tablas, `thead` para los encabezados, `tbody` para los datos y `th` con `scope` para indicar si los encabezados describen filas o columnas.
Asigné un identificador a la sección de recorridos guiados para enlazarla directamente desde la página principal.
Debajo de las tablas agregué la información sobre casco y candado, los horarios de salida y la lista de elementos que los clientes deben llevar.
También incorporé el logo mediante una ruta relativa que sube un nivel desde `paginas/` hasta la carpeta `img/`. Verifiqué los enlaces y revisé Network para detectar posibles errores 404.



 Página de reservas

Creé `paginas/reservas.html` con el título principal "Reserva tu bicicleta", el correo de contacto `hola@ruedalibre.example` como enlace y los horarios de atención organizados mediante una lista de definiciones con las etiquetas `dl`, `dt` y `dd`.
Agregué un menú de navegación al comienzo de las tres páginas: Inicio, Tarifas y rutas, y Reservas.
También incorporé al final de cada página un pie de página con el nombre del negocio, el correo de contacto y el año correspondiente.
Añadí enlaces "Reservar ahora" en la página principal y debajo de la tabla de recorridos guiados en la página de tarifas.

 Hallazgos durante la auditoría

1. `index.html`
- Hallazgo: La página contiene el atributo `lang="es"`.
- Corrección: Se mantiene, ya que identifica correctamente el idioma español.

2. `tarifas.html`
- Hallazgo: Se encontraron etiquetas mal cerradas y enlaces con estructura incorrecta.
- Corrección: Se deben organizar las etiquetas y corregir los enlaces.

3. `reservas.html`
- Hallazgo: La navegación contiene etiquetas `<li>` sin una lista `<ul>` y una etiqueta `</ul>` sobrante.
- Corrección: Se debe organizar correctamente la lista de enlaces.

4. `index.html`
- Hallazgo: Las imágenes tienen atributos `alt` y `width` definidos.
- Corrección: Se mantienen para describir las imágenes y establecer su ancho.

5. `tarifas.html` y `reservas.html`**
- Hallazgo: Los estilos de las tablas están escritos dentro de la etiqueta `<body>`.
- Corrección: Se recomienda trasladarlos a un archivo CSS.

6. `reservas.html`
- Hallazgo: La fila de cierre de la tabla no tiene su etiqueta de apertura `<tr>`.
- Corrección: Se debe agregar para organizar correctamente la tabla.
